网站链接格式详细文档

视频分享平台 · 接口与链接使用说明

一、基础信息

本平台所有接口均基于 HTTP 协议，请求与响应均使用 JSON 格式，编码为 UTF-8。

基础地址：https://yowat.pages.dev

请求格式：application/json

二、视频上传接口

POST/api/upload/{视频标题}/{视频简介}/ 打开后把视频文件拖拽到这个接口显示的网页中间即可完成上传

用于上传视频文件，支持 MP4、WebM 格式，单个文件最大 500MB。

参数名类型必填说明
fileFile是视频文件（multipart/form-data）
titleString是视频标题，最长 50 字
descriptionString否视频简介，最长 200 字

响应示例：

{
  "code": 0,
  "message": "上传成功",
  "data": {
    "video_id": "1",
    "url": "/video/1"
  }
}

三、视频访问链接格式

上传成功后，视频页面链接格式如下：

GET/video/{video_id}

例如：https://yowat.pages.dev/video/1

四、错误码说明

错误码说明
0请求成功
1001参数缺失或格式错误
1002文件格式不支持
1003文件超出大小限制
5000服务器内部错误

五、视频下载接口

视频下载接口如下：

GET/video/getvideo/keyplus{视频id加1}/{video_id}

vid (240p 省流版下载) ：

GET/video/getvideo/back/{video_vid}

例如1：https://yowat.pages.dev/video/getvideo/keyplus2/1

例如2：https://yowat.pages.dev/video/getvideo/back/11092{VIDEO_ID为1}

六、接口的实际落点

站点用 Cloudflare Pages 部署，元数据存在 D1，下面这些路径由 functions/ 里的 Workers 函数接管，直接访问即可：

接口实际地址说明
GET /api/videos /api/videos 视频清单（D1 查询，JSON）
POST /api/upload/{标题}/{简介}/ /api/upload/{标题}/{简介}/ GET 打开上传页；POST 把元数据写进 D1
GET /video/{video_id} /video/1 302 跳转到播放页
GET /video/getvideo/keyplus{id+1}/{video_id} /video/getvideo/keyplus2/1 直接返回 360p 主版本文件（attachment）
GET /video/getvideo/back/{video_vid} /video/getvideo/back/11092 直接返回 240p 省流版文件（attachment）

两个下载接口返回的是视频文件本身，带 Content-Disposition: attachment，支持 Range 断点续传。播放页面上不提供下载按钮——下载只作为接口存在，符合「视频页只管播放」的定位。

站点上不保留高清原片，每个视频只有两个档位文件：videos/{id}/{id}-360.mp4（主版本，播放页默认加载）和 videos/{id}/{id}-240.mp4（省流版，体积约 360p 的 2/3）。播放器下方可以切换这两个档位，360p 加载失败会自动退到 240p。文件由 npm run pack -- --id {id} 生成，上一步的原始高清文件在打包时会被删掉。

注：以上地址需要部署到 Cloudflare Pages 后才生效。本地用 file:// 双击打开时，只有页面能用，接口需要 npx wrangler pages dev . 才能跑起来。

⚠️ 提示：接口地址和参数按当前实现编写。改了数据库字段或路由后，记得同步更新本文档 docs.html。
